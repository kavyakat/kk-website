# Kavya Kathuria — Personal Website

Personal portfolio site built with Next.js 14, TypeScript, and Tailwind CSS.

## Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

## Structure

Single scrolling page with CSS scroll-snap. Five sections:

- **Hero** — name, title, links
- **About** — bio and resume download
- **Experience** — horizontal carousel of roles
- **Skills** — grouped skill tags
- **Contact** — email and social links

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment

Deployed via Vercel. Every push to `main` triggers a redeploy.

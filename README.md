# Kavya Kathuria — Personal Website

Personal portfolio site. Live at **[kavyakathuria.vercel.app](https://kavyakathuria.vercel.app)**.

## Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel (auto-deploy on push to `main`)
- **Analytics:** Vercel Analytics

## Structure

Single scrolling page with CSS scroll-snap. Six sections:

- **Hero** — name, title, links, profile photo
- **About** — bio and resume download
- **Experience** — horizontal carousel of roles
- **Skills** — grouped skill tags
- **Beyond Work** — hobbies and interests
- **Contact** — email and social links

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
